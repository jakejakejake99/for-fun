# f1 telemetry data project

random project where i create and share data for f1 using the FastF1 library. 
the goal is to fetch, process, and visualize real-world f1 telemetry data so that i (and others) can analyze driver performance.

## what it does
- **data collection:** retrieves f1 session data using FastF1.
- **visualization:** displays dashboards for speed, braking, throttle, and lap times using Tkinter and Matplotlib.
- **sharing:** provides a framework for generating and sharing f1 telemetry insights.
